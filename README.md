# VibeCircle

A mobile application built with React Native and Expo Router.

## Features

- **Authentication**: Onboarding, Sign Up, Login, and Profile Creation flows
- **Discovery**: Interest chips, category exploration, and dynamic feature cards
- **Activities & Messages**: Activity feed, messaging tabs, and user profile management
- **Custom UI System**: Cohesive theme tokens, glass effects, custom inputs, buttons, and avatar pickers

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npx expo start
   ```

3. **Run on specific platforms**:
   - **Web**: `npx expo start --web`
   - **Android**: `npx expo start --android`
   - **iOS**: `npx expo start --ios`
